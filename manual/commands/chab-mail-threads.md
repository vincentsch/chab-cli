# chab mail threads

## Usage

```text
chab mail threads [flags]
```

## Description

Work with mail threads.

Thread list and show commands return draft-free Chab message projections for a
selected project and connection.

Related commands:
- [chab mail search](chab-mail-search.md)
- [chab mail messages body](chab-mail-messages-body.md)

## Subcommands

- [chab mail threads list](chab-mail-threads-list.md) - List mail threads (preview)
- [chab mail threads show](chab-mail-threads-show.md) - Show a mail thread (preview)

## Output modes

none (command family)

## Authentication

Runs without requiring a credential.
