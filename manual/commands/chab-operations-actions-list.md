# chab operations actions list

## Usage

```text
chab operations actions list [flags]
```

## Description

List local action records without exposing private recovery material.

Use --json for structured output and --plain for tab-separated rows.

Related commands:
- [chab operations actions show](chab-operations-actions-show.md)
- [chab operations resume](chab-operations-resume.md)

## Examples

```text
  chab operations actions list
  chab operations actions list --json
  chab operations actions list --plain
```

## Output modes

human, JSON, plain

## Authentication

Runs without requiring a credential.
