# chab search

## Usage

```text
chab search [flags]
```

## Description

Run search operations.

Related commands:
- [chab operations](chab-operations.md)

## Subcommands

- [chab search serp](chab-search-serp.md) - Start a SERP search operation (preview)
- [chab search web](chab-search-web.md) - Start a web search operation (preview)

## Output modes

none (command family)

## Authentication

Runs without requiring a credential.
