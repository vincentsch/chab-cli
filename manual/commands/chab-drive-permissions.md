# chab drive permissions

## Usage

```text
chab drive permissions [flags]
```

## Description

Work with drive permissions.

Permission updates use Chab's supported grant/update/revoke shape only. Public
links, inherited permissions, ownership transfer and provider-native sharing
options are not exposed.

Related commands:
- [chab drive items show](chab-drive-items-show.md)
- [chab operations wait](chab-operations-wait.md)

## Subcommands

- [chab drive permissions update](chab-drive-permissions-update.md) - Update drive item permissions (preview)

## Output modes

none (command family)

## Authentication

Runs without requiring a credential.
